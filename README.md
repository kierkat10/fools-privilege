Fool's Privilege is a Vanilla centered mod made with the goal of expanding base game, maintaining the core balance while also adding fun and original ideas. Over 100 New Jokers and more to come! Started by Niicotino.

Total Jokers: 98

Unique Art: 21/98

Note: The art is currently in a development state. Every time new art is added, the number will be updated as well as the version.

It adds over 98 types of jokers, with new content besides jokers planned in the future.
